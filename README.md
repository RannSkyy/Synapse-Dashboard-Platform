# 🏢 GlassHR — Modern Human Resource Dashboard

## 📖 Overview

GlassHR is a premium Human Resource Management dashboard inspired by modern SaaS products. It combines elegant glassmorphism visuals, interactive analytics, employee management tools, department tracking, direct messaging, and productivity-focused workflows into a single immersive experience.

The application showcases a floating macOS-style dashboard layered above a beautiful rolling hills background while maintaining excellent performance and usability.

---

## ✨ Key Features

| Feature Category             | Description                                                                                        |
| ---------------------------- | -------------------------------------------------------------------------------------------------- |
| 🎨 Glassmorphic Dashboard    | Floating macOS-inspired dashboard with blur effects, depth, shadows, and premium visual styling.   |
| 📊 Interactive Analytics     | Animated SVG charts displaying employee growth, department statistics, and document storage usage. |
| 🔄 Live Tab Switching        | Instantly switch between Departments, Employees, and Documents without page refresh.               |
| 🔍 Real-Time Search          | Dynamic filtering system for departments and employee records.                                     |
| ➕ Create Department Modal    | Interactive modal for adding new department data directly into the dashboard.                      |
| 📄 Smart Pagination          | Functional pagination with synchronized table content across pages.                                |
| 💬 Direct Messages Chat      | Interactive chat module supporting two-way messaging between users.                                |
| ⚡ High Performance Rendering | Optimized assets, charts, and animations for smooth user experience.                               |
| 📱 Fully Responsive          | Seamless experience across desktop, tablet, and mobile devices.                                    |
| 🎯 Modern UX Flow            | Clean navigation, intuitive interactions, and accessible user interface.                           |
